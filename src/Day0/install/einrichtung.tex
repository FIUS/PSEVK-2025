\aufgabe{WLAN - iOS und Android}
\begin{itemize}
	\item Im AppStore bzw. Playstore nach „geteduroam“ suchen und die App installieren
	\item Dann nach Universität Stuttgart suchen
	\item Nun Student wählen und eure Daten eingeben
	\item stxxxxxx@stud.uni-stuttgart.de - Benutzername und Passwort eingeben
	\item Nun auf Verbinden klicken und fertig
\end{itemize}

Um das WLAN für euren Laptop aufzusetzen braucht ihr die App von Eduroam. Hierfür müsst ihr euch entweder Hotspot geben (oder eure Nachbarn fragen), wenn dies nicht möglich ist, haben wir auch einen USB Stick mit der relevanten Datei, meldet euch dafür gern bei den Helfern.

\aufgabe{WLAN - MacOS}
\begin{itemize}
	\item Im Internet auf „uni-stuttgart.de/eduroam“ gehen
	\item Klicke auf "continue"
	\item Melde dich mit deinem ST-Account an
	\item Klicke auf "Request new cert"
	\item Gebe dem Zertifikat eine Bezeichnung
	\item Scrolle nach unten und klicke auf macOS/iOS/iPadOS und lade dort das Zertifikat herunter
	\item Offne die Einstellungen, klicke ganz open auf "Profil heruntergeladen" und klicke dort zwei mal auf das Eduroam Zertifikat
	\item Klicke links auf "installieren"
\end{itemize}

\aufgabe{WLAN - Linux}
\begin{itemize}
	\item Im Internet auf „uni-stuttgart.de/eduroam“ gehen
	\item Dann auf Continue Klicken
	\item "Request new cert" => "Device name or description"-> Confirm form
	\item Wenn ihr NetworkManager benutzt, laded das Zertifikat im PKCS\#12 Format herunter und nutzt dieses für Eduroam.
	\item Ihr könnt Details dazu in der Tablelle dadrunter oder im Konfigurations Portal.
	\item Falls ihr wpa\_supplicant direkt benutzt, ladet die Zertifikatsdatei im PEM Format herunter und folgt den Konfigurationsanweisungen auf der Seite.
\end{itemize}

\aufgabe{JDK - Installation}
Wir benötigen ein JDK (Java Development Kit), um Java Programme zu schreiben und
auszuführen.
\begin{itemize}
	\item IntelliJ öffnen
	\item File/Datei gehen oben links in der Menüleiste
	\item Auf \texttt{Project Structure} klicken
	\item Dann auf \texttt{SDKs}
	\item Dann auf das + Symbol klicken und auf \texttt{Download JDK}
	\item OpenJDK Version \vkJdkVersion\ verwenden
	\item Microsoft OpenJDK als Anbieter/Vendor auswählen
	\item Speicherort auswählen (Standardpfad sollte reichen)
\end{itemize}

\aufgabe{Projekt erstellen}
\begin{itemize}
	\item In IntelliJ auf neues Projekt erstellen/ New Project clicken
	\item Java auswählen und das Projekt PSEVorkurs nennen
	\item Nun nen geeigneten Speicher Ort auswählen Achtung: KEIN Git Repository erstellen
	\item Als Build System IntelliJ verwenden und als JDK die gerade heruntergeladene auswählen
	\item Wir wollen keinen Sample Code
\end{itemize}

Es sollte nun so bei euch aussehen:

\includegraphics[width=1\linewidth]{../img/projektCreation.png}

\begin{itemize}
	\item Nun auf Create klicken und das Projekt wird erstellt
	\item Nun links in der Projektansicht auf src rechtsklicken und eine neue Java Klasse erstellen
	\item Diese Klasse Main nennen und auf Enter drücken
	\item Nun sollte sich eine neue Datei öffnen, in der wir unseren Code schreiben
\end{itemize}
