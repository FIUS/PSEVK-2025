\aufgabe{Präsentations-Cheatsheet}
\textbf{Funktionen und Scopes:}
\begin{itemize}
    \item Funktionen helfen Code auszulagern und mehrfach zu nutzen
          \begin{minted}[fontsize=\scriptsize,linenos=false]{java}
public static double avg(double a, double b, double c) {
    return (a + b + c) / 3;
}
          \end{minted}
    \item \texttt{return} gibt einen Wert zurück und beendet die Funktion
    \item Scopes: Variablen nur im jeweiligen Block sichtbar
          \begin{minted}[fontsize=\scriptsize,linenos=false]{java}
int x = 5;
if (x > 0) {
    int y = 10; // y nur hier sichtbar
}
System.out.println(y); // Fehler!
          \end{minted}
\end{itemize}

\textbf{Arrays:}

\begin{itemize}
    \item Arrays speichern mehrere Werte gleichen Typs
    \item Zugriff über Index, Start bei \texttt{0}
          \begin{minted}[fontsize=\scriptsize,linenos=false]{java}
int[] zahlen = new int[5];
zahlen[0] = 42;
System.out.println(zahlen[0])
          \end{minted}
          \begin{ausgabe}
              42
          \end{ausgabe}
    \item Initialisierung auch direkt möglich:
          \begin{minted}[fontsize=\scriptsize,linenos=false]{java}
String[] grill = {"Wurst", "Steak", "Mais"};
          \end{minted}
    \item Mit \texttt{.length} über alle Elemente iterieren:
          \begin{minted}[fontsize=\scriptsize,linenos=false]{java}
for (int i = 0; i < grill.length; i++) {
    System.out.println(grill[i]);
}
          \end{minted}
\end{itemize}

\aufgabe{Aufgabe 3: 2-Dimensionale Arrays}
Ein 2-Dimensionales Array ist eine Art Tabelle. Wir können uns das vorstellen wie ein Array, das in jedem Element ein weiteres Array speichert.

Man erstellt es mit zwei Paar eckigen Klammern. Das erste Paar steht für die Zeile, das zweite für die Spalte (\texttt{[Zeile][Spalte]}).

Wenn du zum Beispiel ein Array mit 3 Zeilen und 2 Spalten erstellst (\texttt{new int[3][2]}), sieht das graphisch so aus:

\begin{center}
\renewcommand{\arraystretch}{1.5} % Macht die Zellen etwas höher und lesbarer
\begin{tabular}{c | c | c |}
\multicolumn{1}{c}{} & \multicolumn{1}{c}{\textbf{Spalte 0}} & \multicolumn{1}{c}{\textbf{Spalte 1}} \\ \cline{2-3}
\textbf{Zeile 0} & \texttt{array[0][0]} & \texttt{array[0][1]} \\ \cline{2-3}
\textbf{Zeile 1} & \texttt{array[1][0]} & \texttt{array[1][1]} \\ \cline{2-3}
\textbf{Zeile 2} & \texttt{array[2][0]} & \texttt{array[2][1]} \\ \cline{2-3}
\end{tabular}
\end{center}

Mit z.b \texttt{array[0][0]} bekommen wir den Inhalt vom ersten Feld oben links.

Hier ein Code Beispiel:
\begin{minted}{java}
int[][] einArray = new int[3][3]; //ein zweidimensionales Array der Größe 3x3
einArray[0][2] = 3; // wir geben dem Feld in Zeile 0, Spalte 2 den Wert 3
System.out.println(einArray[0][2]);
    \end{minted}
          \begin{ausgabe}
              3
          \end{ausgabe}

\begin{enumerate}

\aufgabe{Aufgabe 4: Rekursive Palindrome}
Gestern habt ihr bereits geprüft, ob ein Wort ein Palindrom ist. Heute wollen wir dieses Problem auf eine völlig neue, elegantere Art lösen: mit Arrays und Rekursion! Rekursion ist ein Konzept, bei dem eine Funktion sich selbst aufruft (Rekursion ist ein mächtiges Werkzeug und wird euch noch häufig begegnen).
\begin{enumerate}
    \item Lies mithilfe des Scanners ein Wort ein und wandle dieses in ein Zeichen-Array um. \\
    \textit{Hinweis:} Mit der Funktion \texttt{String.toCharArray()} kannst du einen \texttt{String} in ein \texttt{char[]}-Array umwandeln. \\
    \url{https://docs.oracle.com/javase/8/docs/api/java/lang/String.html#toCharArray--}
    \item Schreibe eine Funktion, die das Array als Parameter übergeben bekommt und prüft, ob das erste und das letzte Element gleich ist. Sind die Zeichen gleich, soll \texttt{true} zurückgegeben werden, andernfalls \texttt{false}.
    \item Schreibe eine weitere Funktion welche das erste und letzte Element des Arrays entfernt und das neue Array zurückgibt.
    \item Schreibe nun die finale, rekursive Methode welche prüft ob das eingegebene Wort ein Palindrom ist. Nutze dafür deine Hilfsfunktionen aus den vorherigen Teilaufgaben!
    
Kombiniere die Vergleichs-Logik aus Teilaufgabe 2 mit deiner Kürzungs-Funktion aus Teilaufgabe 3: Falls die Buchstaben an den Rändern gleich sind, soll die Methode sich selbst mit dem gekürzten Array aufrufen. 
    
\textit{Hinweis zur Rekursion:} Jede rekursive Methode benötigt zwingend eine Abbruchbedingung, da sie sonst unendlich oft weiterläuft. Überlege dir logisch: Ab welcher Array-Größe steht zweifelsfrei fest, dass der verbleibende Rest ein Palindrom ist?
    
Rufe deine fertige Methode zum Testen in deiner \texttt{main}-Methode auf.
\end{enumerate}

Higherformer-Aufgabe 3.:
\begin{minted}[linenos=false]{java}
    public static int[] bubbleSort(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - i - 1; j++) {
                if (arr[j] > arr[j + 1]) {
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }
        return arr;
    }
    \end{minted}
