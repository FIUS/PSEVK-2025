\aufgabe{Präsentations-Cheatsheet}

\bigskip
\textbf{Schleifen:}
\begin{itemize}
    \item \texttt{while}-Schleife: läuft, solange Bedingung \texttt{true} ist
          \begin{minted}[fontsize=\footnotesize,linenos=false]{java}
while (!eingabe.equals("ok")) {
  eingabe = scanner.nextLine();
}
          \end{minted}
    \item \texttt{for}-Schleife: Zählergesteuerte Schleife
          \begin{minted}[fontsize=\footnotesize,linenos=false]{java}
for (int i = 0; i < 5; i++) {
  System.out.println(i);
}
          \end{minted}
    \item \textbf{\texttt{break}}: beendet Schleife vorzeitig
    \begin{minted}[fontsize=\footnotesize, linenos]{java}
Scanner scanner = new Scanner(System.in);

String passwort = "diegrillung";
String abbruchBedingung = "abbruch";
String momentaneEingabe = "";

while (!momentaneEingabe.equals(passwort)) {
    momentaneEingabe = scanner.nextLine();

    if (momentaneEingabe.equals(abbruchBedingung)) {
        break;
    }
}
System.out.println("I'm in");
\end{minted}

\end{itemize}

\aufgabe{Aufgabe 1: While Schleifen}
\begin{enumerate}
    \item Wir bauen den Passwort Checker aus der Vorlesung. Lege ein Passwort fest welches so lange abgefragt wird, bis der Nutzer das richtige Passwort eingibt. Nutze dafür eine While Schleife.
    \begin{ausgabe}
        //Beispiel mit dem Passwort LeckerBierchen\\
        Passwort eingeben: 1234\\
        Passwort falsch!\\
        Passwort eingeben: Hallo\\
        Passwort falsch!\\
        Passwort eingeben: LeckerBierchen\\
        Passwort richtig, erfolgreich eingeloggt!
    \end{ausgabe}
    \item Erweitere den Passwort Checker, sodass der Nutzer nur 3 Versuche hat. Nach dem dritten Fehlversuch soll das Programm mit einer entsprechenden Meldung abbrechen.

    \item Schreibe ein Spiel, bei dem das Programm eine Zufallszahl zwischen 1 und 100 generiert, die der Nutzer erraten soll. Nach jedem Tipp gibt das Programm einen Hinweis aus, ob die gesuchte Zahl größer oder kleiner als der eingegebene Tipp ist. Das Spiel endet, sobald die Zahl korrekt erraten wurde. Nutze dafür wieder die Random Klasse: \url{https://docs.oracle.com/javase/8/docs/api/java/util/Random.html}
        \begin{ausgabe}
            //Beispiel mit der Zufallszahl 61\\
            Dein Tipp: 42\\
            Die gesuchte Zahl ist größer als 42\\
            Dein Tipp: 71\\
            Die gesuchte Zahl ist kleiner als 71\\
            Dein Tipp: 55\\
            Die gesuchte Zahl ist größer als 55\\
            Dein Tipp: 66\\
            Die gesuchte Zahl ist kleiner als 66\\
            Dein Tipp: 61\\
            Richtig geraten! Die Zahl war 61
        \end{ausgabe}
\end{enumerate}

\aufgabe{Aufgabe 2: Zinseszins mit For-Schleifen}
\begin{enumerate}
    \item Schreibe ein Programm, dass den Effekt des Zinseszinses auf ein Startkapital sichtbar macht. Hierfür soll der Nutzer das Startkapital, den Zinssatz sowie die Laufzeit eingeben. Das Programm soll dann für jedes Jahr den neuen Kontostand berechnen und ausgeben. 
        \begin{ausgabe}
            Startkapital eingeben: 400\\
            Zinssatz in Prozent eingeben: 6\\
            Laufzeit eingeben: 5\\
            Der Kontostand nach Jahr 1 beträgt: 424.0\\
            Der Kontostand nach Jahr 2 beträgt: 449.44\\
            Der Kontostand nach Jahr 3 beträgt: 476.4064\\
            Der Kontostand nach Jahr 4 beträgt: 504.990784\\
            Der Kontostand nach Jahr 5 beträgt: 535.2902310400001\\
        \end{ausgabe}
    \item Erweitere das Programm, sodass man zusätzlich eine monatliche Sparrate angeben kann ,welche jeden Monat investiert wird. Das Programm soll dann wieder für jedes Jahr den neuen Kontostand berechnen und ausgeben.
\end{enumerate}

\aufgabe{Aufgabe 3: Spaß mit Zahlen}
Nutze für diese Aufgabe keine String oder Char Variablen sondern reine Zahlenarithmetik.
\begin{enumerate}
    \item Lies eine ganze Zahl ein und gib aus, wie viele Stellen diese Zahl hat. Überlege hierfür, wie man mit mathematischen Operatoren eine Stelle der Zahl abschneiden kann.\\ Beispiel: Die Zahl 1234 hat 4 Stellen
    \item Berechne die Quersumme einer Zahl. Die Quersumme ist die Summe aller Ziffern einer Zahl. \\Beispiel: Die Quersumme von 1234 ist 1+2+3+4=10.
    \item Lies eine Zahl ein und gib diese zweimal direkt hintereinander als eine einzige Zahl aus.\\ Beispiel: Die Zahl 1234 wird zu 12341234 \\ Hinweis: Bei großen Zahlen kann es sinnvol sein long statt int zu nutzen.
    \item Schreibe ein Programm, welches vom Nutzer eine Zahl einliest und sie rückwärts wieder ausgibt.
    \item Schreibe ein Programm, dass vom Nutzer eine Zahl einliest und prüft, ob diese ein Palindrom ist. Palindrome sind Wörter, die rückwärts gelesen dasselbe Wort wie vorwärts gelesen sind (z.b. 12321).
\end{enumerate}

\aufgabe{HIGHPERFORMER: Wordle aber anders}
In der Highperformer-Aufgabe geht es darum das Rätselspiel Wordle (oder Mastermind für die Älteren unter euch) nachzubauen, mit dem Unterschied das Zahlen geraten werden. 

\begin{enumerate}
    \item Generiere eine Zufallszahl mit einer festen Anzahl an Stellen.
    \item Es ist möglich die Farbe von Ausgaben zu bestimmen. Wenn man einen bestimmten Farb-Char vor eine Ausgabe und einen Reset-Char hinter einer Ausgabe schreibt, dann wird nimmt der Text zwischendrin die Farbe an. Kopiere folgenden Code und teste die Farben kurz:
\begin{minted}[linenos=false]{java}
String GREEN = "\u001B[92m";
String YELLOW = "\u001B[93m";
String RESET = "\u001B[0m";
System.out.println(YELLOW + "Gelb " + RESET + GREEN + "Grün" + RESET);
\end{minted}
    \item Lies vom Nutzer wiederholt Zahlen ein und gib jeweils aus inwieweit sie mit dem Ergebnis übereinstimmen. Zähle die Anzahl der Versuche und gib dem Nutzer am Ende aus, wieviele Versuche gebraucht wurden.
    \begin{enumerate}
        \item Korrekt geratene Ziffern, welche an der richtigen Stelle stehen sollen Grün ausgegeben werden.
        \item Jede geratene Ziffer, die zwar in der Lösungszahl vorkommt, aber eben nicht an der richtigen Stelle soll als Gelb ausgegeben werden. 
        \item Ziffern die überhaupt nicht in der Lösungszahl vorkommen sollen Farblos ausgegeben werden.
    \end{enumerate}
    Hier ein paar Beispiele zum selbsttest:
\begin{ausgabe}
Die gesuchte Zahl ist: 418538\\
209726\\
\textcolor{green}{41}6\textcolor{yellow}{8}2\textcolor{yellow}{5}\\
\textcolor{yellow}{8}8\textcolor{green}{8}\textcolor{yellow}{4}44\\
\textcolor{green}{418}\textcolor{yellow}{35}7\\
\textcolor{green}{418538}
\end{ausgabe}
    \item Überlege dir, wie man dieses simple Spiel optimal, d.h. mit so wenig versuchen wie möglich lösen könnte und schreibe ein Programm das dir sagt was du in jeder Situation raten sollst. Die Musterlösung ist ein definitiv nicht optimaler Algorithmus der bei 6 Stellen im Durchschnitt 21.3 Versuche benötigt. Vielleicht kannst du das ja knacken.
\end{enumerate}
