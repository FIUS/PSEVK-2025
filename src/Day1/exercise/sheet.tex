\aufgabe{Aufgabe 2: Scanner}
Während das Programm ausgeführt wird können auch Werte aus der Konsole eingelesen werden. Dies geht mit einem Scanner-Objekt. Mit \texttt{scannerObjekt.next()} wird die nächste eingegebene Zeile eingelesen. Mit \textbf{Enter} wird die Eingabe beendet.\\
Hinweis: Kommentiert am besten die Aufgaben aus, die ihr schon erledigt habt, sonst werden irgendwann bei jedem Durchlauf all eure Lösungen ausgeführt werden.
\begin{minted}[linenos=false]{java}
Scanner derScanner = new Scanner(System.in);
System.out.println("Gib deinen Namen ein: ");
String deinName = derScanner.nextLine();
System.out.println("Du heißt " + deinName);
\end{minted}
\begin{ausgabe}
	Gib deinen Namen ein: Melanie\\
	Du heißt Melanie
\end{ausgabe}
Wobei die obere Melanie vom Nutzer eingegeben wird.

\begin{enumerate}
	\item Programmiere einen Addierer, der zwei Zahlen einliest und die Summe ausgibt. Mit \texttt{Scanner.next()} funktioniert etwas nicht, überlegt mal warum (Tipp im \hyperlink{Aufgabe_2.1}{Codeanhang})?
	      \begin{ausgabe}
		      Gib eine Zahl ein: 12\\
		      Gib noch eine Zahl ein: 3\\
		      Die Summe ist: 15
	      \end{ausgabe}
	\item Programmiere ein Modulo-Übungsprogramm, bei dem erst zwei Zahlen mit dem Scanner eingegeben werden. Anschließend soll der Nutzer versuchen die Lösung von \texttt{zahl1 \% zahl2} selbst zu berechnen und einzugeben. Am Schluss soll dann das korrekte Ergebnis ausgegeben werden.
	      \begin{ausgabe}
		      Gib eine Zahl ein: 14\\
		      Gib noch eine Zahl ein: 3\\
		      Gib dein Ergebnis ein: 6\\
		      Das richtige Ergebnis von 14 \% 3 ist: 2
	      \end{ausgabe}
	\item Schreibe eine kurze Geschichte (oder suche dir einen kurzen Text im Internet). Suche dann ein paar Wörter mit ihren Wortarten aus und lass den Nutzer sie mit dem Scanner durch andere ersetzen. Gib dann die Geschichte mit den vom Nutzer eingegebenen Wörtern aus. Zum Beispiel wird: ''\textit{Die \underline{PSE}-Vorkurs Hauptorgas lieben \underline{grillen}.}'' \space zu:
	      \begin{ausgabe}
		      Gib ein Thema ein: backen\\
		      Gib ein Verb ein: Ofen sprengen\\
		      Die backen-Vorkurs Orgas lieben Ofen sprengen.
	      \end{ausgabe}
	      Lass deine Sitznachbarn und/oder die Helfer dein Programm ausführen ohne, dass sie wissen welcher Text dahinter steckt.
\end{enumerate}

\aufgabe{Aufgabe 4: Schere Stein Papier}
Java stellt einen Zufallszahlengenerator zur Verfügung. Er wird ähnlich wie ein Scanner initialisiert und er besitzt unter anderem folgende Funktionen:

\begin{minted}[linenos=false]{java}
Random rndGenerator = new Random();

//gibt ein zufälligen float zwischen 0.0 und 1.0 zurück:
float zufallsFloat = rndGenerator.nextFloat();

//gibt ein zufälligen int zwischen 0 und 9 zurück (10 wird als Obergrenze ausgeschlossen)
int zufallsInt = rndGenerator.nextInt(10);
\end{minted}
Die Offizielle Dokumentation für Random findet ihr hier: \url{https://docs.oracle.com/javase/8/docs/api/java/util/Random.html}
\begin{enumerate}
	\item Überlege dir ein System, wie der Computer mithilfe des Zufallszahlengenerators eine eigene Wahl für Schere, Stein oder Papier treffen kann, und setze es im Code um.
	\item Programmiere darauf aufbauend ein Spieler vs. Computer Spiel. Lies die Wahl des Nutzers als Zahl über die Konsole ein, vergleiche sie mit dem Computerzug und gib den Gewinner aus.
	\item Berechne den Spielausgang mit einer einzigen Modulo-Formel. Du darfst die Variablen für die Wahl des Spielers und des Computers in deinen If-Bedingungen gar nicht mehr direkt erwähnen oder vergleichen. Ausgewertet wird ausschließlich das Ergebnis deiner Rechenformel!
	\item Erweitere das Spiel um Echse und Spock. Überlege wie man die Reihenfolge der Symbole anordnen muss damit die Modulo-Formel weiterhin funktioniert. Die Regeln sind wie folgt:
	      \begin{itemize}
		      \item Schere köpft Echse \& schneidet Papier
		      \item Stein zerquetscht Echse \& zertrümmert Schere
		      \item Papier bedeckt Stein \& widerlegt Spock
		      \item Echse frisst Papier \& vergiftet Spock
		      \item Spock zertrümmert Schere \& verdampft Stein
	      \end{itemize}
\end{enumerate}

\aufgabe{HIGHPERFORMER-Aufgabe: Pseudozufällige Zahlen}
Vor allem in der Cybersecurity, aber auch in anderen Anwendungen wie Prozeduralen Systemen, sind Zufallszahlen sehr wichtig. 
Echter Zufall ist nahezu unmöglich mit Computern zu erschaffen, deswegen werden oft pseudo-random-number-generators (Generatoren von "Pseudozufälligen" Zahlen) genutzt um aus einer kleinen, hoffentlich zufälligen Seed-Zahl größere Mengen an zufälligen Zahlen zu generieren, diese Generatoren sind Deterministisch, d.h. sie müssen für ein und denselben Seed immer dieselben Zufallszahlen generieren. Hierbei ist es sehr wichtig, das die Generatoren keine Muster aufweisen, da diese im Cybersecurity Beispiel für einen Angriff genutzt werden können. Hier baut ihr so einen pseudo-random-number-generator.
\begin{enumerate}
	\item Modifiziere dein Moduloübungsprogramm aus Aufgabe 2.2 so, dass die beiden Anfangszahlen nicht mehr selbst eingegeben werden sondern so, dass diese zufällig generiert werden. Der Nutzer soll immer noch selber versuchen das Ergebnis zu berechnen.
	\item Ladet euch das Rahmenprogramm hier: \newline \url{\vkUrlDayOneHighperformer}  \newline  herunter.
	      \newline Dort bekommt ihr einen sogenannten Seed (eine 5-Stellige Zahl) vom eingebauten Java Zufallsgenerator. Generiert mit den mathematischen Operatoren die ihr jetzt kennt anhand dieses Seeds eine neue 10-Stellige Zufallszahl (ihr dürft natürlich nicht die \texttt{Random} Klasse verwenden). Wir (die PSE-Vorkurs Orgas) haben ein Testerprogramm geschrieben, dass versucht eure Lösung zu bewerten und eventuelle Schwächen eures Ansatzes aufzuzeigen, doch wenn ihr Lust habt könnt ihr auch versuchen den Test auszutricksen. Wenn ihr einen funktionierenden Ansatz habt, könnt ihr versuchen die Aufgabe noch auf eine andere Art zu lösen.
\end{enumerate}
